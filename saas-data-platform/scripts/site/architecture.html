How it's built · dbt + DuckDB

From raw to report in five layers. Every layer tested.

The whole platform is one dbt project. Raw tables land, staging cleans them, intermediate holds the business logic, marts hold one grain each, and the serving layer is what people and AI agents query. This page is generated from dbt's own model graph, so it always matches the code.
