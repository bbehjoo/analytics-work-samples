Private by default — forget a rule and the data disappears, it doesn't leak

The safe outcome is the default one, so a mistake fails closed
No tag, no column

A column with no classification is hidden from every role. A new column stays inside HR's own tables until someone decides who may see it.

Private models

Raw HR models are private to People Analytics. A revenue model that references them fails to compile.

Under 5, hidden

No people metric is shown for fewer than 5 people, because a number about two people is a number about a person.

Keys, not records

Revenue joins people through a bridge that holds two hashed keys and nothing else.

The proof — tests that run on every build

Each test returns the rows that break its rule, so zero rows is a pass · loosen the policy, say by giving analysts raw pay, and the build fails
